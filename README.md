## 💎 Features
- **The Sanaria Edit:** High-fashion editorial campaign panels (New Arrivals, The Evening Edit, Everyday Essentials, Signature Collection).
- **Runway Video Showcase:** Interactive model runway video player with direct product linking and shopping bag integration.
- **Admin Portal (`/#admin`):**
  - **Video Placements Manager:** Dedicated control center to choose, assign, or upload 4K MP4 videos for each store panel (New Arrivals, Evening Edit, etc.).
  - **Product Management:** Add/edit products with multiple images, high-speed IndexedDB video storage, size and stock management.
  - **Live Order Management & Invoice Printing:** Direct customer dispatch with nationwide Iraqi governorate delivery.
  - **CMS & Banners Management:** Instant live updates without code redeployment.
- **Bilingual & Multi-Language Support:** Full RTL/LTR support for Arabic, Kurdish, English, and Turkish.
- **Iraq Express Delivery:** Integrated governorate tracking and concierge services.

---

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Custom Luxury Editorial Design System (Vanilla CSS tokens, Cinzel & Cormorant Garamond luxury typography)
- **Icons:** Lucide React
- **Storage:** IndexedDB + LocalStorage fallback for high-capacity media storage

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
The application will launch on `http://localhost:3000`.

### 3. Build for Production
```bash
npm run build
```
Production assets will be generated in the `dist/` directory, ready to deploy to your hosting server.
